# Tienda de Cristal

Programas para instalar con un clic desde **Cristal > Tienda**.

- `tienda.json` es la lista de programas que ve Cristal.
- Cada versión de cada programa es una *release* de este repositorio (etiqueta `programa@versión`) con su archivo y su icono.

No hace falta tocar nada aquí a mano: los programas se suben, se actualizan y se quitan desde Cristal.
